## 每张任务卡必须包含

```text
1. Phase 目标
2. 任务列表
3. 上游输入
4. 下游输出
5. 契约
6. 边界
7. 实施步骤
8. Definition of Done
9. 测试与验收
10. 风险与回滚
11. 状态更新要求
```
