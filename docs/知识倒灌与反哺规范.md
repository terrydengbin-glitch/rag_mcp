# 知识倒灌与反哺规范

本项目允许其他业务项目把专业知识、审计结论、bad case、实盘事故经验、回测偏差发现、LLM/RAG 经验反哺到 CEK-TA。但任何倒灌内容都不能直接进入通用知识库，必须经过去项目私有化、来源补全、冲突检查、审计批准和版本记录。

## 倒灌目标

```text
业务项目产生经验。
CEK-TA 提炼通用知识。
通用知识再服务更多项目。
```

## 可倒灌内容

```text
1. 专业理论补充
2. 官方文档或交易所规则更新
3. 回测偏差案例
4. 模拟盘撮合问题
5. 实盘风控事故经验
6. 交易 bad case 标签
7. 策略审计模式
8. LLM 训练样本设计经验
9. RAG 检索失败与修复经验
10. Vue3 审计界面改进建议
```

## 禁止直接倒灌内容

```text
1. API key、账户、密钥、私有 token
2. 真实账户敏感数据
3. 未脱敏订单明细
4. 未脱敏用户、团队、客户信息
5. 业务项目私有字段定义
6. 只对单个项目成立的临时配置
7. 无来源、无证据、只有感觉的结论
8. 与已有 approved 规则冲突但未说明适用边界的规则
```

## 倒灌流程

```text
业务项目发现
  -> 创建倒灌任务卡
  -> 脱敏与去项目私有化
  -> 补充来源和证据
  -> 归类到 domain/subdomain
  -> 与已有知识做冲突检查
  -> 生成候选知识条目
  -> 人工或 Codex 审计
  -> approved 后进入 CEK-TA
```

## 倒灌状态

```text
proposed: 业务项目提出
sanitized: 已脱敏和去项目私有化
sourced: 已补充来源
classified: 已归类
conflict_checked: 已完成冲突检查
reviewed: 已审计
accepted: 已接收进入 CEK-TA
rejected: 已拒绝
needs_more_evidence: 需要补充证据
```

## 去项目私有化规则

倒灌内容必须把项目事实和通用知识拆开：

```text
项目事实：
当前字段叫 micro_fast
当前策略版本是 v3.2
当前回测命令是 python run_backtest.py

通用知识：
盘口特征缺失时不能用价格涨跌方向直接替代真实主动买卖压力
回测命令、字段名、策略版本不能写入通用知识
```

## 冲突处理

如果倒灌内容与 CEK-TA 已有规则冲突，不能直接覆盖。

必须输出：

```text
1. 冲突规则
2. 冲突类型
3. 双方来源等级
4. 双方适用市场
5. 双方数据粒度
6. 双方前置假设
7. 推荐保留方式
8. 是否需要废弃旧规则
```

## 入库验收

倒灌内容进入 CEK-TA 前必须满足：

```text
1. 已脱敏
2. 已去项目私有化
3. 已补充来源
4. 已标注适用范围
5. 已完成冲突检查
6. 已指定 domain/subdomain
7. 已生成知识条目或 Skill 修改建议
8. 已记录贡献来源项目
```

## Vue3 审计界面要求

Vue3 知识审计界面需要支持倒灌队列：

```text
1. 查看 proposed 倒灌任务
2. 查看来源项目和贡献类型
3. 查看脱敏状态
4. 查看来源完整度
5. 查看冲突检查结果
6. 执行 accept/reject/needs_more_evidence
7. 查看倒灌后生成的知识条目
```
