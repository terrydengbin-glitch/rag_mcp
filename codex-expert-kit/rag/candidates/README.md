# CEK-TA Ingestion Candidates

This directory stores Phase 23 ingestion candidate packages before they are reviewed and converted into formal knowledge drafts.

Rules:

```text
1. Candidate packages must follow codex-expert-kit/rag/ingestion_candidate_schema.md.
2. Candidate packages are not approved knowledge.
3. MCP default search must not treat candidates as default guidance.
4. Rejected or unresolved-conflicted candidates must stay out of formal indexes.
5. Chinese content must be UTF-8.
```
