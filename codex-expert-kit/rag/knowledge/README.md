# CEK-TA Formal Knowledge Store

This directory stores formal CEK-TA knowledge items.

Rules:

```text
1. Store only reviewed, approved, deprecated, or explicitly auditable draft items.
2. Default retrieval should use approved items first.
3. Do not store proposed contributions here.
4. Do not store secrets, account data, raw orders, or project-private field dictionaries.
5. Every item must follow ../knowledge_item_schema.md.
6. Every approved item must include tree_node_id and tree_path.
```

Proposed contributions belong in:

```text
../../../contributions/proposed/
```
